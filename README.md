# 🚀 Viral Script AI Agent

An advanced **AI-powered viral content generation workflow** built using **n8n + Gemini AI + automation pipelines**.

This system analyzes viral videos, reverse-engineers their structure, and automatically generates:

* 🎬 Viral video scripts
* 🧠 Hook & storytelling analysis
* 📝 Professional production notes
* 📱 Reels/Shorts shooting guides
* 🎨 Content structure for creators
* 📄 Beautiful downloadable PDF outputs

---

# ✨ What This Workflow Does

This system reverse-engineers viral content using Gemini AI.

You provide:

* Viral video
* Topic
* Target format
* Brand voice
* Audience

The workflow then:

1. Analyzes the viral video
2. Detects hooks & storytelling patterns
3. Generates a new viral-style script
4. Creates production notes
5. Exports everything into PDFs
